# English C2: Zakria's English

An installable offline web app (PWA) for going from B2/C1 to C2 English, with Arabic meanings. It's a LingQ-style reader, Anki-style cards, spelling and dictation practice, IELTS writing practice and a B2 → C2 plan. There's no server and no account: everything is stored on your device.

**Open it:** https://hellozakria-dotcom.github.io/english/

- **Android:** open the link in Chrome → ⋮ menu → *Install app* (or *Add to Home screen*).
- **Windows / Mac / Linux:** open it in Chrome or Edge → click the install icon in the address bar.

## Features
- **Placement test.** About 110 yes/no words sampled from frequency bands 1k → 30k, with fake-word checks. It estimates your vocabulary size and CEFR level, and marks every band you clearly know as *already known*. Those words are never counted as learned.
- **Word counter.** It counts dictionary words (lemmas): *run / ran / running* = one word. A word counts as **learned** only if it was new to you and its card reaches a 3-week interval (or you mark a word you've been studying as known).
- **Reader.** Graded texts from B2 to C2 in four styles: news, film/TV dialogue, IELTS reading and listening (with questions) and academic essays. You can also **import your own text**. Hover (desktop) or tap (phone) a word or phrase to see:
  - the Arabic meaning, English definitions, American IPA and voice
  - the part of speech, register (formal / informal / academic), frequency band and AWL sublist
  - collocations, phrasal verbs, and 2–3 usage examples that are never the sentence you're reading
  - buttons: *Add to cards* / *I know this*

  Colours: blue = new, yellow = learning, none = known. Phrasal verbs and idioms (including separable ones like *turn it off*) are looked up as one unit. You can also select several words to look up a phrase.
- **Practise learning words in sentences.** Fill-in-the-blank with real sentences (a different one each time), a practice text made of your learning words, or a story written by an AI chat from a prompt the app prepares.
- **Cards.** Spaced repetition (Again / Hard / Good / Easy). There's a vocabulary deck and a **spelling deck**, where you hear the word, type it and see letter-by-letter mistakes.
- **Write**
  - Dictation (words and sentences) with a letter-by-letter diff. Mistakes go into **My misspellings**, which comes back with spaced repetition.
  - 11 spelling rules and 48 confusing pairs (affect/effect, their/there…) with a quiz.
  - IELTS Task 1 (charts, table, process) and Task 2 essays: timer, word count, automatic checks (spelling, repetition, linkers, academic words), a self-check list, band descriptors and self-marking.
- **Plan.** Units from your level to C2: vocabulary bands to 15k (word builder), the Academic Word List sublists 1–10, 12 advanced grammar lessons with exercises, collocation quizzes, idiom sets and IELTS tasks. It shows counters and an **honest time estimate** based on your placement result, new cards a day and minutes a day.
- **Home.** Daily goal ring, streak and a **Continue** button that picks your next step.
- **Backup.** *Settings → Save backup / Load backup* moves your progress between phone and computer. Loading merges, so nothing is lost.

## Project layout
```
index.html            the whole app (HTML + CSS + JS, no build step needed to run)
manifest.webmanifest  install info · icons/
sw.js                 offline cache (generated by tools/build.py)
dict/core.json        lemma list by frequency, word forms → lemma, phrases, AWL
dict/d_*.json         dictionary entries, one file per first letter (cached for offline use)
dict/fakes.json       fake words for the placement test
content/texts.md      graded texts ← edit these
content/curated/*.txt hand-written dictionary entries (Arabic with harakat per meaning + 2 examples) ← edit these
content/learn.py      spelling rules, confusing pairs, IELTS tasks, grammar, idioms ← edit these
tools/build.py        texts.md → texts.json, learn.py → learn.json, generates sw.js
tools/build_dict.py   rebuilds dict/ from the open sources (run tools/setup.sh first),
                      then tools/postprocess.py, tools/rerank.py, tools/build_colloc.py, tools/curated.py
```

## Adding a text
Add a block to `content/texts.md`:
```
=== my-id | news | C1 | Title of the text
Q: Optional question || Answer
---
Paragraph one…

Paragraph two…
```
The styles are `news`, `dialogue` (lines like `ANNA: text`), `ielts-reading`, `ielts-listening` and `academic`. Then run `python3 tools/build.py`, commit and push.

## Data sources and licences
- [Princeton WordNet 3.0](https://wordnet.princeton.edu/): definitions, examples, synonyms, phrasal verbs (WordNet licence)
- English Wiktionary translations via [@langle/en-ar](https://www.npmjs.com/package/@langle/en-ar) and lemmas via [@langle/en](https://www.npmjs.com/package/@langle/en): Arabic meanings and phrases (CC BY-SA 4.0)
- [Arabic WordNet](https://github.com/omwn/omw-data) (CC BY-SA 3.0) and [FreeDict/Arabeyes eng-ara](https://github.com/freedict/fd-dictionaries) (GPL): Arabic fallbacks
- [wordfreq](https://github.com/rspeer/wordfreq) (frequency bands), [FrequencyWords](https://github.com/hermitdave/FrequencyWords) (spoken vs written register), [ipa-dict](https://github.com/open-dict-data/ipa-dict) (IPA), [spaCy lookups](https://github.com/explosion/spacy-lookups-data) (lemmas)
- Brown and Reuters corpora (via NLTK): usage examples and collocations
- Academic Word List: Coxhead (2000)

Because of the CC BY-SA sources, the dictionary data in `dict/` is shared under **CC BY-SA 4.0**. The texts, exercises and code were written for this app.
